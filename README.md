# Tracking Smoke Test

This small repository is intended to generate a few observable engineering events:

- Repository activity: a commit containing these files.
- File activity: adding and editing `tracking_smoke_test.py`.
- Compilation activity: compiling the module with Python.

Run the syntax compilation check and smoke test from the repository root:

```powershell
node --check tracking_smoke_test.js
node tracking_smoke_test.js
```

This repository contains no chat content.
